# Prime V2

Primeira tela visual, feita do zero a partir da referência clara enviada em 03/10/2026. Sem componentes, estilos, catálogo ou backend do Prime V1.

`npm run dev` → http://localhost:5174

`npm run build` → valida o frontend.

Apenas a interface inicial: navegação, recolhimento da sidebar, menus e temas. O campo central e voz são prévias; não há geração, busca de produtos ou conexão com contas. Nenhuma publicação em produção.

As dependências disponíveis no projeto pai permitem executar agora. Se mover esta pasta para fora do projeto, execute `npm install` primeiro.
